# KidsIQ Boost - Interactive Learning Platform

![KidsIQ Boost](https://img.shields.io/badge/Education-Interactive%20Learning-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Version](https://img.shields.io/badge/Version-1.0.0-orange)

A responsive and interactive educational website designed to help children develop intelligence through fun learning activities and games.

## 🎯 Features

- **Math Challenges** - Improve numerical skills with interactive math problems
- **Memory Games** - Enhance cognitive function with matching games
- **Pattern Recognition** - Develop logical thinking with pattern sequences
- **Progress Tracking** - Visual progress chart and statistics
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Child-Friendly Interface** - Colorful, engaging, and easy to use

## 🚀 Live Demo

[View Live Website](https://sanaullah-gondal.github.io/KidsIQ-Boost---Interactive-Learning-Platform/)

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Charts**: Chart.js for progress visualization
- **Icons**: Emoji icons for child-friendly interface
- **Design**: Responsive CSS Grid and Flexbox layouts
